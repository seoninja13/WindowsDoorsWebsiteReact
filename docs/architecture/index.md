## Key Architectural Decisions

1. **Next.js App Router**: We use the Next.js App Router for routing and server-side rendering.
2. **Static Site Generation (SSG)**: We use SSG with Incremental Static Regeneration (ISR) for optimal performance.
3. **TypeScript**: We use TypeScript for type safety and better developer experience.
4. **Tailwind CSS**: We use Tailwind CSS for styling and responsive design.
5. **Component-Based Architecture**: We follow a component-based architecture for code organization and reusability.
6. **API Routes**: We use Next.js API routes for server-side functionality.
