# Integrations

> **Breadcrumb Navigation**: [README.md](../../README.md) > [Documentation](../index.md) > Integrations

## Overview

This document provides an overview of all integrations used in the Windows Doors Website React project. These integrations enable the project to interact with external services and APIs.

## Integrations

### MCP Servers

- [Context7 MCP Server](./context7-mcp-server.md) - Provides access to knowledge bases of many other MCP servers
- [Supabase MCP Server](./supabase-mcp-server.md) - Enables interaction with Supabase through the Model Context Protocol
- [Crawl4AI MCP Server](./crawl4ai-mcp-server.md) - Provides web crawling and screenshot functionality

### External Services

- [Supabase](./supabase.md) - Database, authentication, and storage
- [Google Maps API](./google-maps-api.md) - Maps and location services
- [Form Submission APIs](./form-submission-apis.md) - APIs for form submissions

## Usage

Each integration has its own documentation page with detailed information on configuration, usage, and troubleshooting.
